# 심박 측정 · 화생컴공 (2026 챌린지데이)

아두이노 + MAX30102 심박 센서로 손끝 맥박을 재고, 보통 상태 / 집중 상태 / 거짓말 탐지기 게임을 진행하는 부스 프로그램이에요.

- **설치가 필요 없어요.** 폴더를 통째로 복사해서 `START.html`을 Chrome이나 Edge로 열면 끝이에요. 인터넷도 필요 없어요.
- **아두이노 라이브러리도 설치하지 않아요.** 펌웨어는 아두이노 기본 기능만 써요.
- 센서가 없을 때는 **시뮬레이션 모드**로 화면을 미리 볼 수 있어요.

```
START.html            ← 이것만 열면 돼요 (Chrome / Edge)
START-Windows.bat     ← 윈도우에서 더블클릭하면 Chrome/Edge 앱 창으로 열어 줘요
arduino/HeartSensor/  ← 아두이노에 올릴 펌웨어
app/                  ← 화면(디자인 파일)과 신호 처리 코드, 오프라인용 라이브러리
tests/                ← 박동 검출 테스트 (개발용)
```

---

## 1. 배선

| MAX30102 | 아두이노 우노/나노 |
|---|---|
| VIN | 5V (모듈에 3.3V만 적혀 있으면 3.3V) |
| GND | GND |
| SDA | A4 |
| SCL | A5 |
| INT | 연결 안 함 |

> 센서를 찾지 못한다고 나오면(`센서 없음`) 먼저 점퍼선이 헐겁지 않은지 보세요.
> 그래도 안 되면 준비한 **4.7kΩ 저항 2개**로 SDA–3.3V, SCL–3.3V 사이를 각각 이어 주세요(풀업 저항).
> 일부 저가형 모듈은 풀업이 1.8V에 걸려 있어서 우노가 신호를 못 읽는 경우가 있어요. 모듈 뒷면에 1.8V/3.3V를 고르는 납땜 점퍼가 있으면 3.3V 쪽으로 옮겨 주세요.

## 2. 펌웨어 올리기 (아두이노마다 한 번, 펌웨어가 바뀌면 다시)

1. 아두이노 IDE에서 `arduino/HeartSensor/HeartSensor.ino`를 열어요.
2. 보드(예: Arduino Uno)와 포트를 고르고 **업로드**해요. 추가로 설치할 라이브러리는 없어요.
3. 확인하고 싶으면 도구 → 시리얼 플로터(115200 baud)를 열어 보세요. 손가락을 올리면 맥박 모양의 파형이 보여요.
   **확인한 뒤에는 시리얼 모니터/플로터를 꼭 닫아 주세요.** 열려 있으면 프로그램이 포트를 쓸 수 없어요.

## 3. 프로그램 실행

1. 아두이노를 USB로 연결해요.
2. `START-Windows.bat`을 더블클릭하거나, `START.html`을 **Chrome 또는 Edge**로 열어요.
   (기본 브라우저가 다른 경우: `START.html` 오른쪽 클릭 → 연결 프로그램 → Chrome/Edge)
3. 오른쪽 위 **`센서 연결하기`** 배지를 누르고 → **`센서 연결`** → 목록에서 아두이노(또는 `USB-SERIAL CH340`, `USB Serial`)를 골라요.
4. 배지가 초록색 **`센서 연결됨`** 으로 바뀌면 준비 끝이에요. 화면 전환(측정 ↔ 실습)을 해도 연결은 유지돼요.
5. 부스 화면은 `F11`로 전체 화면을 쓰면 깔끔해요.

USB를 뽑았다 다시 꽂으면 **자동으로 다시 연결**돼요. 프로그램을 새로 열었을 때는 브라우저 설정에 따라 `센서 연결`을 한 번 더 눌러야 할 수 있어요.

### 다른 컴퓨터에서 쓰기

- 이 폴더 전체를 USB 메모리 등으로 복사하면 돼요. GitHub에서는 **Code → Download ZIP**으로 받은 뒤 압축을 풀어 주세요.
- 필요한 것: Chrome 또는 Edge(데스크톱). 인터넷·설치·관리자 권한 모두 필요 없어요.
- 호환 보드(CH340 칩)를 처음 꽂았을 때 포트가 안 보이면 CH340 드라이버를 한 번 설치해야 할 수 있어요.
- 노트북 3대를 쓰면 노트북마다 아두이노 1개씩 연결하면 돼요.

## 인식률을 높이기 위해 들어간 것

**아두이노 펌웨어**
- **LED 밝기 자동 조절**: 손가락 두께·피부색·누르는 힘에 따라 반사되는 빛의 양이 크게 달라요. 0.2초마다 신호 크기를 보고, 빛이 너무 세서 신호가 잘리면(포화) 바로 줄이고, 약하면 키워서 알맞은 범위(최대값의 약 35~85%)에 맞춰요.
- **18비트 해상도 + 4회 평균**: 1초에 400번 재서 4개씩 평균 → 잡음이 줄어든 신호를 1초에 100번 보내요.
- **손가락 감지**: 반사되는 빛의 양으로 손가락이 올라왔는지 판단하고, 없을 때는 LED를 약하게 켜 둬서 손가락을 올리는 순간 신호가 잘리지 않게 해요.
- **배선 흔들림 대비**: 센서를 10ms마다 한 번씩만 읽어 통신 횟수를 줄였고(초당 약 400번), 통신이 잠깐 실패해도 0.2초까지는 무시하고 계속 재요. 센서가 정말 빠졌다 다시 연결되면 맞춰 둔 LED 밝기를 그대로 이어서 써요. I2C 속도는 값싼 모듈·긴 점퍼선에서도 안정적인 100kHz를 써요.
- **LED 밝기 안정화**: 손가락이 자리 잡은 뒤에는 누르는 힘이 조금 바뀌어도 밝기를 자주 바꾸지 않아요(넓은 범위를 0.6초 넘게 벗어날 때만).

**PC 프로그램 (`app/heart-sensor.js`)**
- **대역 통과 필터 + 밝기 정규화**: 0.3~5Hz만 남기고, 신호를 밝기(DC)로 나눠 % 단위로 바꿔서 사람마다 다른 밝기에 영향을 받지 않게 해요.
- **기울기 기반 박동 검출**: 혈액이 밀려올 때 신호가 가장 가파르게 올라가는 순간을 찾아요(Elgendi 방식의 두 이동평균 비교). 호흡 때문에 출렁이는 기준선과 이완기의 작은 물결(중복맥)을 박동으로 잘못 세지 않아요.
- **진짜 맥박 확인**: 박동마다 파형 모양이 앞선 박동들과 닮았는지(모양 일치도), 또는 신호가 일정한 주기로 반복되는지 확인한 뒤에만 박동을 화면에 보내요. 사람은 숨 쉴 때마다 박동 간격이 10~20%씩 출렁여서 주기만 보면 놓치기 쉬운데, 모양은 거의 그대로라 안정적으로 인정돼요. 맥동이 너무 작거나(세게 눌러 맥박이 없음) 반사광이 약하면(손가락 없음) 엄격하게 걸러서 엉뚱한 숫자가 뜨지 않아요.
- **LED 밝기가 바뀌어도 끊기지 않기**: 밝기가 바뀌면 처음부터 다시 분석하지 않고 밝기 비율만큼 보정해서 계속 이어서 재요.
- **움직임·이상값 제거**: 맥박으로는 나올 수 없는 큰 출렁임은 움직임으로 보고 버리고, 너무 빨리 반복되는 봉우리(이중 검출)도 걸러요.
- **두 채널 자동 선택**: 적외선(IR)과 적색(Red)을 함께 분석해서 더 깨끗한 쪽을 써요. LED 하나가 고장 난 보드에서 잡음뿐인 채널로 넘어가지 않도록, 맥박처럼 반복되는 채널로만 바꿔요.
- **이중 계산 방지**: 이완기 물결(중복맥)이 큰 사람은 한 박동을 두 번 셀 수 있는데, 짧은·긴 간격이 번갈아 나타나면 이를 알아채고 바로잡아요. 그동안에는 틀린 BPM을 보여주지 않아요.
- **정밀한 박동 간격**: 포물선 보간으로 10ms(샘플 간격)보다 정밀하게 RR 간격을 재고, PC 시계로 센서 샘플 속도를 보정해요.
- **실시간 안내**: `손가락 없음`, `맥박을 찾고 있어요`, `움직이지 말고 그대로 있어 주세요`, `신호가 약해요 · 누르는 힘을 살짝 빼거나…` 처럼 지금 무엇을 고치면 되는지 센서 카드에 보여줘요.

합성 신호 테스트(`node --test tests/dsp.test.js`)에서 느린/빠른 심박(40~150 BPM), 아주 약한 맥박(관류지수 0.1%), 큰 중복맥, 호흡 출렁임, 움직임, LED 밝기 변화 상황 모두 박동을 94% 이상 정확하게 잡도록 맞췄어요(대부분 100%).

## 현장에서 인식률을 높이는 요령

1. **손가락 끝 가운데(지문 부분)** 를 센서 창 한가운데에 올려요.
2. **세게 누르지 않기.** 세게 누르면 혈관이 눌려 맥박이 약해져요. 살짝 닿을 정도가 가장 좋아요.
3. **손이 차가우면** 손을 비비거나 따뜻한 물건을 잠깐 쥐게 한 뒤 재요.
4. **움직이지 않기.** 팔을 책상에 올려 두고 말하지 않도록 안내해요.
5. 센서를 책상에 테이프로 고정하거나, 벨크로/고무줄로 손가락을 **가볍게** 감아 두면 누르는 힘이 일정해져요.
6. 햇빛이 강한 창가는 피하고, 손가락으로 센서 창을 완전히 덮어요.
7. 그래도 박동을 자주 놓치면 설정 패널에서 **측정 민감도를 4~5**로, 박동이 아닌데 숫자가 튀면 **1~2**로 바꿔 보세요.

## 센서 설정 패널

오른쪽 위 배지를 누르면 열려요.

| 항목 | 설명 |
|---|---|
| 연결 | 센서 연결/해제, `센서` ↔ `시뮬레이션` 전환 |
| 신호 | 신호 품질(막대 4칸), 실시간 파형, 심박수, 관류지수(맥동 크기), 규칙성, 사용 채널 |
| 측정 민감도 | 1(잡음에 강함) ~ 5(약한 맥박도 감지), 기본 3 |
| LED 밝기 | 자동(권장) 또는 직접 조절. IR 신호가 9만~22만이면 알맞은 밝기예요 |
| 기록 | 잡은 박동의 시각·BPM·RR 간격·신호 품질을 **CSV로 저장** (엑셀에서 열려요). 민감도별 신뢰도 비교 실험에 쓸 수 있어요 |
| 원신호 저장 | 최근 약 2분 동안 아두이노가 보낸 값을 그대로 파일로 저장해요. 측정이 잘 안 될 때 원인 분석용이에요 |

## 문제 해결

| 화면에 보이는 것 | 원인 / 해결 |
|---|---|
| `센서 연결 불가` | Web Serial을 지원하지 않는 브라우저예요. Chrome 또는 Edge로 여세요 |
| 포트 목록이 비어 있음 | USB 케이블(충전 전용 케이블이 아닌지), CH340 드라이버를 확인하세요 |
| `포트를 열 수 없어요` | 아두이노 IDE 시리얼 모니터/플로터를 닫으세요. 다른 탭에서 열려 있어도 안 돼요 |
| `데이터 없음` | `HeartSensor.ino`를 업로드했는지 확인하세요 |
| `센서 없음` | 배선(SDA→A4, SCL→A5, VIN, GND)과 위의 풀업 저항 안내를 확인하세요 |
| `센서 없음`·`신호 찾는 중`이 번갈아 깜빡임 | 점퍼선 접촉 불량이에요. 선을 꾹 눌러 끼우거나 짧은 선으로 바꾸세요. 최신 펌웨어를 올렸는지도 확인하세요(잠깐의 통신 오류를 견디도록 바뀌었어요) |
| `손가락 없음`인데 손가락을 올렸음 | 센서 창 위치를 다시 맞추세요. 계속 그러면 설정 패널의 `반사지수`를 보고 펌웨어의 `FINGER_ON`/`FINGER_OFF` 값을 손가락을 올렸을 때와 뗐을 때의 중간으로 바꿔 주세요 |
| `빛이 너무 강함` | 손가락으로 센서 창을 완전히 덮으세요. LED를 '직접 조절'로 바꿔 둔 경우엔 '자동'으로 돌려 주세요 |
| 숫자가 자주 튐 (`오류 가능성` 표시) | 움직임·누르는 힘 변화가 원인이에요. 손을 책상에 올리고 힘을 빼게 하세요 |
| `신호 찾는 중`이 오래 계속됨 | 손가락을 가볍게 올리고 10초 정도 가만히 기다려 보세요. 그래도 계속되면 설정 패널에서 **원신호 저장**을 누르고, 그 파일로 `node tools/replay.js 파일이름` 을 실행하면 1초마다 어디서 막히는지(움직임, 규칙성, 맥동 크기 등) 볼 수 있어요 |

## 개발자용 메모

- **시리얼 형식** (115200 baud): 데이터 `IR값,Red값` 100줄/초, 상태 `#STAT IR전류 Red전류 손가락 반사지수 자동`(0.5초마다), 그 외 `#HELLO`, `#OK`, `#ERR NO_SENSOR|SENSOR_LOST|WRONG_PART`, `#I2C 주소들`, `#OVF n`.
  PC → 아두이노 명령: `A`(LED 자동), `M60`(LED 고정, 1=0.2mA), `R`(센서 재시작), `?`(상태).
- **화면 파일**: `app/*.dc.html`은 디자인 도구에서 만든 파일 그대로이고, 센서 연결 부분만 추가했어요.
  디자인을 다시 내보내 덮어쓸 때는 `<head>`의 스크립트 줄(`vendor/…`, `dc-bundle.js`, `heart-sensor.js`)과 `class Component` 안의 센서 관련 코드(`hs`, `onHs`, `src()` 등)를 남겨 두세요.
- `BpmChart.dc.html`을 고치면 `node tools/build-bundle.js`로 `app/dc-bundle.js`를 다시 만들어 주세요(브라우저가 `file://`에서 다른 파일을 읽지 못해서 미리 묶어 둬요).
- 테스트: `node --test tests/dsp.test.js` (박동 검출 · 합성 신호와 `tests/realppg.js`의 현실적인 손끝 신호), `node tests/e2e.js` (Playwright로 가짜 시리얼 포트를 써서 전체 흐름 확인).
- 원신호 재생: `node tools/replay.js 원신호_….txt [민감도]` — 설정 패널에서 저장한 파일을 그대로 다시 분석해요.
- 포함된 오픈소스: React 18.3.1, three.js r158 (MIT), Pretendard 1.3.9 (SIL OFL) — `app/vendor/licenses/` 참고.
